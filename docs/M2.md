# Milestone M2 — Read-only controller

## Scope delivered

- **`temperature.py`**: Configurable sources, equal-weight average, staleness, unit normalization (entity metadata + `hass.config.units`), physical `current_temperature` fallback.
- **`controller.py`**: Port of `kitchen-climate-state-machine.ts` (pure functions + HA-independent tests).
- **`capabilities.py`**: Physical attribute discovery, optional read-only `sensibo.get_device_capabilities`, per-mode cache, profile fan gating (EP-03–EP-06).
- **`room_store.py`**: Persisted user targets, HVAC mode, controller snapshot fields.
- **Coordinator + climate**: Shadow mode diagnostics, no physical `climate.*` writes.

## Shadow mode

`shadow_mode: true` on virtual climate attributes. Controller and capability outputs are **recommendations only** until M3 actuator.

## Deferred (M3/M4)

- Physical actuator, ack/retry, command serialization (`actuator.py`).
- `boost_expires_at` timer persistence and Boost services (M4).
- Full options UI for temperature source editor (sources via config entry `data` / `options` list today).
- Swing write commands.
- Native `native_*` climate temperature properties (HA 2026.11+).

## Config keys

| Key | Location | Purpose |
|-----|----------|---------|
| `temperature_sources` | entry `data` / `options` | `[{entity_id, attribute?}]` |
| `staleness_seconds` | entry `data` / `options` | Max source age (default 600) |
